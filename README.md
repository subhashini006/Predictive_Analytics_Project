# Predictive Analytics Using Historical Data

This project uses Machine Learning and Linear Regression to predict student writing scores using historical student performance data.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Matplotlib

## Features
- Data preprocessing
- Linear Regression model
- Prediction system
- Accuracy evaluation
- Data visualization

## Output
- R2 Score
- Mean Absolute Error
- Scatter Plot Graph
